asset-bot — Agent Onboarding

Read this file top to bottom and you will understand the entire system: what it does, how it runs, every credential, every known trap, and what is actually broken. Written for an LLM agent picking this up cold.

⚠️ READ FIRST — three facts that change every decision
  • The operator is in Iran. Comprehensive OFAC sanctions apply. Gumroad, Ko-fi, Payhip, Lemon Squeezy, Stripe and PayPal cannot pay out. Do not propose them as revenue. Do not build on USDT/Tron — Tether has frozen ~$475M of Iran-linked USDT and Iran's whole digital-asset sector is sanctionable. Bitcoin Lightning zaps are the only working rail.
  • This API surface lies. Four separate endpoints returned 200 OK for writes that never persisted (Whop banner_image, Whop labels, Whop app base_url, Sell.app product create). Always verify a write by reading it back.
  • Green does not mean working. On 2026-09-04 the daily run reported success while producing 0/3 assets. QC + alerting now exist specifically to stop that. Never trust an exit code alone.

1. What this system is

An autonomous digital-product factory. Every day it invents a topic, generates an AI prompt pack, renders images and video, packages it (MD/PDF/DOCX), publishes it as a product on Whop, and syndicates it across ~22 channels. A Cloudflare Worker is the control plane and public front end.

topics → generate_pack (LLM) → QC gate → media (images+video)
      → packaging (MD/PDF/DOCX) → hosting (GitHub Releases)
      → publish (Whop product + cover + FAQ + marketplace submit)
      → dist_core queue → 22 channel adapters
      → Worker /p/:slug canonical page (+ zap CTA)

3. Schedules & cron architecture

GitHub's schedule: is best-effort and silently drops runs. So Cloudflare Workers cron is the primary trigger (it fires workflow_dispatch), and GitHub's own schedule is a dead-man's fallback that calls POST /api/cronclaim and no-ops if the Worker already ran.

7. Traps — do not relearn these the hard way

TrapReality
Whop cover images5 steps: mediaDirectUpload(record=access_pass) → S3 PUT → mediaAnalyzeAttachment(mediaType=image, lowercase) → attachment(id) query → file_… id → updateAccessPass. The blob id is NOT the attachment id.
Whop marketplace_statusNot returned by GET. Only the publish response has it. Re-POST /publish (idempotent) to read current state.
Whop FAQsNo write API anywhere (0 hits in the 3MB OpenAPI spec). FAQs are an experience (app), or manual.
Whop app permissionsFrozen at install time. Adding a permission later does nothing — the app must be re-installed.
Whop CDN imagesimg-v2-prod.whop.com returns 403 to third parties. Never syndicate those URLs — use GitHub Release copies (release_images).
Cloudflare KVFree tier = 1,000 writes/day. Only write when data actually changed; an idle dashboard tab once burned 90% of quota.
wranglerLatest needs Node ≥22; this box has v20. Always npx --yes wrangler@4.86.0.
BufferchannelId is singular; assets is {image:{url}} not {type,source}; channels query needs input:{organizationId}. Pinterest needs a board id.
Sell.appField is deliverables_type, not type. Create returns 201 but does not persist — channel removed.
Hugging Face/upload/ endpoint is retired (410). Use NDJSON /commit/.
HashnodeFree GraphQL API retired 2026-05-13 — requires Pro.
itch.ioNo create-page API (405/404 everywhere). Page made by hand once; butler pushes builds.
RedditAPI closed (Responsible Builder Policy); commercial tier ~$12k/yr. Do not automate.
EtsyBanned AI prompt bundles (Jul 2024). Do not build.
Nostr keysThe supplied npub and nsec are different accounts. We post with the nsec.
Whop external_identifierNo longer accepted on create — 400s for every value tried (plain, timestamped, alphanumeric); omitting it succeeds. The slug lives in metadata instead.
Free products + DiscoverThe $0 plan must exist BEFORE marketplace.publish(). Publishing first yields "missing: a visible pricing plan" and silently keeps every free asset off Discover. Ordering bug, fixed.
Pack skills keyOptional in practice — the LLM omits it under truncation. Three call sites indexed it directly and a KeyError killed a pack that had already scored 100/100. ensure_shape() now guarantees it.
Distributing paid assetsPaid products are hidden until /approve. Enqueuing at publish time broadcasts a dead link — 4 products once queued 68 such posts. Only enqueue when price == 0; approve() enqueues the rest.
LLM prompt countsModels under-deliver (3 prompts when 10 requested). The generator now asks once for the shortfall rather than lowering the QC bar.
actions/cache on state/Clobbered the git-tracked manifest. Never reintroduce.

8. Operating it

# distribution
cd engine
python3 dist_core.py status        # queue + which channels are armed
python3 dist_core.py drain 10
python3 dist_core.py retry-failed

# nostr profile (after changing the lightning address)
python3 nostr_profile.py

# local dry run (never posts)
MOCK=1 DRY_RUN=1 python3 run_daily.py

# worker
cd workers && npx --yes wrangler@4.86.0 deploy

Safety switches: DIST_POSTING_MODE=DRAFT (default — queues, never posts), DIST_MODE_<CHANNEL>=LIVE per channel, QC_STRICT=0 to disable the quality gate (not advised), plus kill-switch / dry-run toggles in CF KV.

10. House rules for whoever works on this next

  • Verify writes by reading them back. Four APIs here return false 200s.
  • Never claim a credential is dead without testing it against a known-good signal first — that mistake was made three times.
  • Test failure paths, not just happy paths. The circuit breaker looked fine and never tripped until asserted on.
  • Don't automate hostile platforms (Reddit, X direct, LinkedIn direct). Buffer is the sanctioned proxy.
  • Prefer deterministic checks over LLM judgement for QC.
  • Alerts only on exhaustion, deduplicated. Noise trains people to ignore alarms.
